# Supreme Pro Builders Website

Production source for the Supreme Pro Builders residential remodeling and commercial construction website.

## Production workflow

- GitHub is the source of truth.
- Vercel hosts production.
- The approved ChatGPT Site remains the visual baseline.
- SEO, conversion, accessibility, and performance improvements are tracked in `SEO_ROADMAP.md`.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm test
```
